# One-Line Setup

Copy and paste this into your Mac terminal:

```bash
chmod +x ~/Roblox/Roblox/setup-roblox-dev.sh && ~/Roblox/Roblox/setup-roblox-dev.sh
```

That's it! The script will:
- Install everything needed
- Create all config files
- Initialize your project
- Get you ready to build

---

## If that doesn't work:

```bash
bash ~/Roblox/Roblox/setup-roblox-dev.sh
```

---

## If you prefer Node.js instead:

```bash
node ~/Roblox/Roblox/setup-roblox-dev.js
```

---

**Takes about 10-15 minutes.** It will ask for your password once for Homebrew.
